# Barbers — descargas

Instaladores oficiales de **Barbers**, el sistema para barberías.

- **Android (tablets):** `Barbers-Android.apk`
- **Windows 10/11 (64 bits):** `Barbers-Windows-Setup.exe`

Descárgalos desde la sección [Releases](https://github.com/betogol100/barbers-descargas/releases/latest)
o desde la página oficial: https://barbers-app-8us.pages.dev

Este repositorio solo contiene instaladores; no contiene código.
Para usar la app necesitas una cuenta de barbería activa.
